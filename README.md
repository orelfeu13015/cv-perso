# CV web de Cyril Gomez

CV statique réalisé en HTML, CSS et JavaScript natifs. Le projet ne nécessite ni installation ni compilation.

## Prévisualisation

Ouvrir `index.html` dans un navigateur suffit pour consulter le CV. Pour reproduire les conditions d'un hébergement web, lancer un serveur HTTP local depuis la racine du projet.

## Vérifications avant publication

- tester la page sur ordinateur, tablette et téléphone ;
- vérifier le fonctionnement des accordéons et de la navigation interne ;
- imprimer la page en PDF et contrôler les sauts de page ;
- vérifier que toutes les images sont chargées ;
- si un bouton de téléchargement est ajouté, conserver le PDF dans ce dossier et utiliser un chemin relatif commençant par `./`.

## Structure

- `index.html` : contenu, styles et interactions du CV ;
- `assets/photo.jpg` : portrait ;
- `assets/` : portrait et logos des employeurs et clients ;
- `output/pdf/CV-Cyril-Gomez.pdf` : version PDF A4 générée depuis la page.
